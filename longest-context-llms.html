LLMs with the longest context windows

Every model we track, sorted by the maximum number of tokens it accepts in one request.

30 modelsData checked October 10, 2026

Context windows grew from a few thousand tokens in 2022 to a million or more for many current models. The limit covers your prompt, any documents or conversation history you include, and often the response.

The advertised limit is a ceiling, not a guarantee of quality across the whole window. Accuracy on facts deep inside long prompts varies, and long prompts cost more and take longer to process.

How to choose

  • Check the maximum output separately: a huge input window can still come with a modest output limit.
  • Look for long-context surcharges in the price notes.
  • Use the context window visualizer to see what fits.

Frequently asked questions

Which LLM has the largest context window?

The model at the top of this table has the largest advertised window among the current models we track. Very large windows exist mainly on a few models; most current frontier models offer around 1 million tokens.

Does a bigger context window make a model smarter?

No. It only lets the model see more text at once. Quality on long inputs depends on how the model was trained and evaluated for long context, so test with your own documents.
