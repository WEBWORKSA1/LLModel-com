Claude Sonnet 5.5

Claude Sonnet 5.5 is Anthropic's mid-tier model, which the company describes as its balance of speed and intelligence. Released September 28, 2026, it pairs a 1M-token context window with adaptive thinking that defaults to high effort.

Frequently asked questions

How much does Claude Sonnet 5.5 cost?

Claude Sonnet 5.5 lists at $2 per million input tokens and $10 per million output tokens, with cached input at $0.10 (checked October 10, 2026). Standard rates; no surcharge across the 1M-token window. Batch API 50% off. US-only inference adds 1.1x. Confirm current rates on the provider's pricing page before you commit.

What is the context window of Claude Sonnet 5.5?

Claude Sonnet 5.5 accepts up to 1,000,000 tokens of context (about 750,000 words, or 1,500 pages), and it can write up to 125K tokens in a single response. Long prompts cost more and can be slower, so most apps send only what the task needs.

Is Claude Sonnet 5.5 open source?

No. Claude Sonnet 5.5 is a proprietary model from Anthropic; its weights aren't published. You can use it through the Anthropic API and through Claude apps, Amazon Bedrock, Google Vertex AI, Microsoft Azure AI Foundry, Claude Platform on AWS, OpenRouter.

What is Claude Sonnet 5.5 best for?

Anthropic positions Claude Sonnet 5.5 for coding, agents, chat, writing. It accepts text, images, pdf as input, has a reasoning (thinking) mode and supports tool calling. Test it on a sample of your own tasks before you choose it for production.
