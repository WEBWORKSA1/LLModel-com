LLMs you can run locally

Open-weight models small enough to run on a single consumer GPU, a workstation card or a high-memory Mac, with the memory each one needs.

19 modelsData checked October 10, 2026

Running a model on your own machine keeps data private, works offline and costs nothing per token once you own the hardware. The limit is memory: the weights must fit in GPU memory (or Apple unified memory), with room left for the KV cache.

Memory figures below are for the weights at 4-bit quantization (about 4.85 bits per weight), the most common setting for local use. Higher precision roughly doubles (8-bit) or quadruples (16-bit) the requirement.

How to choose

  • 8-12 GB GPUs: models up to about 8B parameters at 4-bit.
  • 16-24 GB GPUs: up to roughly 30B at 4-bit with a moderate context.
  • Macs with 64-128 GB of unified memory: up to about 120B mixture-of-experts models at 4-bit.
  • Size a specific setup with the VRAM calculator and follow our guide to running LLMs locally.

Frequently asked questions

What is the best LLM to run locally?

The best local model is the most capable one that fits your memory with room for context. On a 24 GB GPU that's usually a model of around 20-30B parameters at 4-bit; on a 128 GB Mac, mixture-of-experts models above 100B become practical.

How much RAM do I need to run an LLM?

For GPU inference, count GPU memory: about 0.6 GB per billion parameters at 4-bit for the weights, plus the KV cache. On Apple Silicon, the GPU can use most of the unified memory, so a 32 GB Mac comfortably runs models in the 8-14B range.
