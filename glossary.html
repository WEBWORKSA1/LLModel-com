The unsettled legal questions over training AI models on copyrighted works without permission.

Cosine similarity

A measure of how closely two vectors point in the same direction, widely used to compare embeddings.

How LLM APIs charge: a set price per million input tokens and a usually higher one for output.

Corrupting a model's training data so it learns hidden behaviors, biases or backdoor triggers.

Model capacity reserved for one customer, billed by time instead of per token.

A model that generates text by refining a whole draft in parallel over several steps, not token by token.

Model architecture

Direct preference optimization (DPO) DPO

A simpler alternative to RLHF that trains directly on preferred-versus-rejected answer pairs.

Training

Distillation knowledge distillation, model distillation

Training a smaller student model to imitate a larger teacher model's outputs.

A model that converts text into vectors so that similar meanings produce nearby vectors.

Skills that seem to appear suddenly once models pass a certain scale, rather than improving gradually.

Including a few worked examples in the prompt so the model copies the pattern.

Prompting

Fine-tuning finetuning, model fine-tuning

Further training a pretrained model on a smaller, targeted dataset to change its behavior.

One of the most capable models available at a given time, usually from a well-funded lab.

GPQA GPQA Diamond, Graduate-Level Google-Proof Q&A

GPTQ

GPU (graphics processing unit) graphics card, accelerator

The parallel processor that trains and runs most LLMs; memory size and bandwidth matter most.

Grounding groundedness

Tying a model's answers to specific, verifiable sources such as retrieved documents, data or search results.

Checks placed around a model to block, filter or correct unsafe, off-topic or malformed inputs and outputs.

Combining keyword search and semantic vector search so each covers the other's blind spots.

Supervised training on instruction-and-response examples so a model learns to follow requests.

A neural network trained on huge amounts of text to predict and generate language.

The setting that controls how big a step the model's weights take on each training update.

Lost in the middle

The tendency of models to use information at the start or end of a long input better than the middle.

The cap you set on how many tokens a model may generate in one response.

An architecture that routes each token to a few specialist sub-networks, so only part of the model runs per token.

Model architecture

MLX Apple MLX

Apple's open-source machine learning framework, optimized for running and fine-tuning models on Apple silicon.

A widely cited multiple-choice benchmark covering 57 subjects, from math and law to medicine.

Model card system card

A document describing a model's intended uses, training, evaluation results, limitations and risks.

Quality decay when models are trained repeatedly on data generated by earlier models.

An open standard for connecting AI applications to tools and data sources through a common interface.

The legal terms that govern how you may use, modify and distribute a model's weights and outputs.

Sending each request to the most suitable model, often a cheap one first, with fallbacks for failures.

An application in which several LLM agents with different roles or tools collaborate on a task.

Multimodal multimodal model, multimodal LLM, vision-language model

Able to take in or produce more than one kind of data, such as text, images and audio.

Needle in a haystack NIAH, needle test

A long-context test that hides one fact in a long document and asks the model to find it.

Evaluation and benchmarks

Numeric precision (FP16, BF16, FP8, INT8) data type, dtype, bit width

How many bits are used to store each number in a model, trading accuracy for memory and speed.

Inference and deployment

O

Ollama

A free tool that downloads and runs open-weights models locally with simple commands and an API.

Inference and deployment

On-device AI edge AI, local AI, local LLM

Running models directly on a phone, laptop or other local hardware instead of in the cloud.

Inference and deployment

Open Source AI Definition (OSAID) OSAID

The Open Source Initiative's standard for when an AI system can properly be called open source.

Safety and governance

Open weights open-weight model, open model

A model whose trained parameters are published for anyone to download and run.

Fundamentals

Overfitting

When a model learns its training examples too closely and performs worse on new data.

Training

P

Parallelism (data, tensor, pipeline, expert) distributed training, model parallelism, multi-GPU training

Ways of splitting a model's training or serving across many GPUs so it fits in memory and runs faster.

Training

Parameter-efficient fine-tuning (PEFT) PEFT, parameter-efficient tuning

A family of fine-tuning methods that train a small number of new or selected parameters instead of the whole model.

Training

Parameters weights, parameter count

The learned numbers inside a model; their count is the usual measure of model size.

pass@k pass at k, pass@1

The probability that at least one of k generated attempts at a problem is correct.

Evaluation and benchmarks

Perplexity PPL

A measure of how well a model predicts text; lower means the model is less surprised.

PII (personally identifiable information) personal data, personally identifiable information

Information that can identify a specific person, such as names, emails, phone numbers or ID numbers.

Safety and governance

Positional encoding position embedding, positional embedding

Information added to a transformer so it knows the order of tokens, since attention alone ignores order.

Model architecture

Post-training

Everything done to a pretrained model to turn it into a useful, safer assistant.

Training

Pretraining pre-training

The first, most expensive training stage, where a model learns language by predicting the next token.

Training

Prompt caching context caching, prefix caching

Reusing the processed form of a repeated prompt prefix to cut cost and latency on later requests.

Business and pricing

Prompt chaining chained prompts, LLM chain

Breaking a task into a sequence of prompts where each step's output feeds the next.

Prompting

Prompt engineering prompt design, prompting

Designing and testing the instructions and context you give a model to get reliable results.

Prompting

Prompt injection

An attack that hides instructions in content a model reads, hijacking it to ignore or override its real instructions.

Safety and governance

Prompt template prompt templating, templated prompt

A reusable prompt with placeholders, or the model-specific format that wraps chat messages.

Prompting

Proximal policy optimization (PPO) PPO

A reinforcement learning algorithm that improves a model in small, controlled steps; the classic RLHF optimizer.

Training

Q

QLoRA quantized LoRA

LoRA fine-tuning on top of a 4-bit quantized base model, cutting memory needs dramatically.

Training

Quantization model quantization, weight quantization

Storing a model's numbers at lower precision to cut memory use and speed up inference.

Inference and deployment

Query rewriting query reformulation, query transformation, query expansion

Using a model to reformulate a user's question into better search queries before retrieval.

R

Rate limit API rate limit, quota, throttling

A provider-imposed cap on how many requests or tokens you can send in a given time window.

Business and pricing

ReAct (reason + act) ReAct, reason and act

An agent pattern in which a model alternates between reasoning about a task and taking tool actions.

Building LLM apps

Reasoning model thinking model, large reasoning model

An LLM trained to work through a problem in intermediate steps before giving its final answer.

Fundamentals

Red teaming AI red teaming, adversarial testing

Deliberately attacking a model or AI application to find harmful behaviors and security weaknesses before others do.

Safety and governance

Reinforcement learning from human feedback (RLHF) RLHF

Training a model to produce answers people prefer, using a reward model learned from human rankings.

Training

Reinforcement learning with verifiable rewards (RLVR) RLVR, RL with verifiable rewards

Reinforcement learning where rewards come from automatic checks, such as a correct answer or passing tests.

Training

Repetition penalty frequency penalty, presence penalty

A setting that lowers the scores of tokens already used, to discourage loops and repeated phrases.

Inference and deployment

Reranker reranking model, re-ranker

A model that re-scores an initial list of search results to put the most relevant ones first.

Building LLM apps

Residual connection skip connection

A shortcut that adds a layer's input to its output, keeping signals and gradients flowing through deep networks.

Model architecture

Retrieval information retrieval, IR

Finding and returning the most relevant pieces of information from a collection for a given query.

Building LLM apps

Retrieval-augmented generation (RAG) RAG

Fetching relevant documents at query time and adding them to the prompt so the model answers from them.

Building LLM apps

Reward model preference model, RM

A model trained to score responses by how much people, or a rubric, would prefer them.

Training

Role prompting persona prompting, role-play prompting

Telling a model to adopt a role or persona, such as an experienced editor, to shape its responses.

Prompting

Rotary position embedding (RoPE) RoPE, rotary embedding

A widely used way of encoding token positions by rotating query and key vectors by position-dependent angles.

Model architecture

S

Scaling laws neural scaling laws, Chinchilla scaling

Empirical rules that predict how model quality improves as you add parameters, data and compute.

Training

Self-consistency majority voting

Sampling several independent answers and picking the most common one to improve accuracy.

Prompting

Self-hosting self-hosted LLM, on-premises deployment

Running models on hardware you control, in your data center or cloud account, instead of calling an API.

Inference and deployment

Semantic search vector search, dense retrieval, neural search

Search that matches by meaning rather than exact keywords, usually by comparing embeddings.

Building LLM apps

Serverless inference pay-per-token inference, shared endpoint

Calling models on shared infrastructure and paying only for what you use, with no servers to manage.

Business and pricing

Sliding window attention local attention, windowed attention, SWA

Attention limited to a fixed number of recent tokens, keeping cost and memory from growing with length.

Model architecture

Small language model (SLM) SLM, compact model

A language model small enough to run cheaply or on a single device, often under about 10B parameters.

Fundamentals

Softmax softmax function

A function that turns a list of raw scores into probabilities that are positive and sum to one.

Model architecture

Special tokens control tokens, reserved tokens

Reserved tokens that mark structure, such as the start of a message or the end of output.

Fundamentals

Speculative decoding speculative sampling, assisted generation

A speed-up where a small model drafts several tokens and the large model checks them all at once.

Inference and deployment

State space model (SSM) SSM, state-space model

A sequence architecture that carries a fixed-size running state instead of attending over every past token.

Model architecture

Stop sequence stop token, stop string

A string that tells the model to end generation as soon as it produces it.

Inference and deployment

Streaming token streaming, streamed responses

Sending a model's output to the client piece by piece as it is generated, rather than all at once.

Inference and deployment

Structured outputs structured generation, constrained generation

Forcing a model's output to follow a defined format, typically valid JSON matching a schema you supply.

Building LLM apps

SWE-bench SWE-bench Verified

A benchmark that tests whether a model or agent can resolve real GitHub issues in Python projects.

Evaluation and benchmarks

Sycophancy AI sycophancy

A model's tendency to tell users what they want to hear rather than what is accurate.

Safety and governance

Synthetic data model-generated data

Training or test data generated by a model or program rather than collected from people.

Training

System prompt system message, developer message, system instructions

Standing instructions, set by the developer, that shape a model's behavior for an entire conversation.

Prompting

T

Temperature sampling temperature

A sampling setting that controls how random or predictable a model's word choices are.

Inference and deployment

Test-time compute inference-time compute, inference-time scaling, test-time scaling

Extra computation spent while answering, such as longer reasoning, to get better results.

Inference and deployment

Throughput aggregate throughput, system throughput

How much work a system completes per unit of time, such as total tokens per second across all users.

Inference and deployment

Time to first token (TTFT) TTFT

How long a model takes to start responding after receiving a request.

Inference and deployment

Token

The basic unit of text a language model reads and writes, often a word or word fragment.

Fundamentals

Token budget context budget, token allowance

A planned limit on how many tokens a request, user, feature or task may consume.

Business and pricing

Tokenization tokenizer

Splitting text into the tokens a model uses, and mapping each one to an ID number.

Fundamentals

Tokens per second output speed, TPS, tok/s

How fast a model generates output, the standard measure of LLM generation speed.

Inference and deployment

Tool calling function calling, tool use

Letting a model request that your code run a defined function, then using the result in its answer.

Building LLM apps

Top-k sampling top_k

A sampling setting that restricts each choice to the k most likely next tokens.

Inference and deployment

Top-p (nucleus sampling) nucleus sampling, top_p

A sampling setting that limits choices to the smallest set of tokens covering a set share of probability.

Inference and deployment

Transformer transformer architecture

The neural network design behind nearly all modern LLMs, built around the attention mechanism.

Model architecture

Tree of thoughts (ToT) ToT

A technique where a model explores and evaluates multiple branching lines of reasoning, backtracking as needed.

Prompting

V

Vector database vector store, vector index

A database built to store embeddings and quickly find the ones most similar to a query.

Building LLM apps

vLLM

A popular open-source engine for serving LLMs at high throughput on GPUs.

VRAM (GPU memory) video RAM, GPU memory

The memory on a GPU, which must hold the model's weights plus working memory to run it.

Inference and deployment

W

Watermarking AI watermarking, AI watermark

Embedding a hidden, detectable signal in AI-generated content so it can later be identified as machine-made.

Zero data retention (ZDR) ZDR, no data retention

An arrangement in which an AI provider does not store your prompts and outputs after processing them.
