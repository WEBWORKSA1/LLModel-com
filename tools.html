Seven calculators and builders for the questions that come up on every LLM project: what will it cost, will it fit, which model, and how do I phrase it. No sign-up, and what you type stays in your browser.

Which tool do you need?

Budgeting a feature? Start with the cost calculator: enter tokens per request and requests per day, and it ranks every priced model by monthly bill. If you don't know your token counts, paste a typical prompt into the token counter first.

Choosing a model? The model picker asks five questions and returns three candidates with the reasons. Put them side by side in the compare tool, then test them on your own data.

Thinking about self-hosting? Check whether a model fits your GPU or Mac with the VRAM calculator, then see whether renting GPUs beats paying per token at your volume with the break-even calculator.

Working with long inputs? The context window visualizer turns token limits into pages, books and hours of transcript. And when you're ready to write the prompt itself, the prompt builder assembles a structured one from your answers.

Frequently asked questions

Are these LLM tools free?

Yes, all of them, with no account. They run entirely in your browser: the text you paste into the token counter or prompt builder isn't uploaded anywhere.

Where do the prices come from?

From each provider's official pricing page, checked on the date shown on the tool. Every model page lists the exact sources. Prices change often, so confirm on the provider's site before you commit to a budget.

How accurate is the VRAM calculator?

The weights figure is exact arithmetic on the parameter count and precision. The KV cache figure is an estimate that depends on each model's attention design, which the calculator accounts for where it's known. Leave headroom of 10-20% for real deployments.
