Methodology

The index scores each current model with a published list price from 0 to 1 on six factors, multiplies each score by your weight, and rescales the total to 100. Legacy models and models without a confirmed price are left out so that every model is scored on the same inputs.

  • Capability tier. Frontier scores 1.0, advanced 0.75, efficient 0.5 and compact 0.3, plus 0.05 for a reasoning mode. Tiers are our editorial grouping of provider positioning and public benchmark standings; they are not our own test results.
  • Low price. Blended price (three parts input to one part output) on a log scale: the cheapest model scores 1, the most expensive 0. A log scale stops a single very expensive model from flattening everyone else.
  • Context window. Maximum context on a log scale between the smallest and largest window in the set.
  • Open weights. 1 if you can download the weights, 0 if not. License terms vary, so read them on the model page.
  • Inputs. One third of a point for each non-text input type (images, audio, video or PDF), capped at 1.
  • Newer release. Release date scaled between the oldest and newest model in the set.

The index is a shortlisting aid. It can't tell you which model writes the best answer for your task; only a test on your own data can. For raw capability, check the independent leaderboards below, which run their own evaluations.

Independent leaderboards and benchmarks

  • Hugging Face HubThe main public registry for open models, datasets and demo apps, hosting millions of repositories with model cards and version history. Search it when you need open weights, a dataset or a reference implementation.Freemium
  • Arena (formerly LMArena)A public leaderboard built from anonymous side-by-side votes, where people compare two models' answers without knowing which is which. Treat it as one signal of conversational quality, alongside task-specific benchmarks.Free
  • Artificial AnalysisIndependent comparisons of AI models and API providers on intelligence scores, price, output speed and latency. Handy when you are choosing both a model and a host and need quality and cost side by side.Free
  • LiveBenchA benchmark built to resist test-set contamination, using questions refreshed over time and scored automatically against ground-truth answers. Check it for objective comparisons of reasoning, coding and math ability across models.Free
  • Epoch AI Benchmarking HubEpoch AI's database of benchmark results, mixing evaluations the team runs itself with figures from outside sources. Use it to see how leading models score on hard tasks and to compare them across several tests.Free
  • SWE-benchA benchmark of real GitHub issues from Python repositories, with public leaderboards for variants such as Verified, Multilingual and Lite. Use it to judge how well a model or coding agent resolves genuine software tasks.Open source
  • Stanford HELMStanford's Holistic Evaluation of Language Models, an open framework and living set of leaderboards that score models across many scenarios and metrics rather than accuracy alone. Use it for transparent, reproducible comparisons.Open source

Frequently asked questions

What is the best LLM right now?

It depends on what you weigh. With the default balanced weights, the top of this index is a mix of frontier models and strong mid-priced ones. If price matters most, efficient models jump ahead; if you need to self-host, open-weight models lead. Independent benchmark leaderboards linked on this page track raw capability.

Do you run your own benchmarks?

No. The capability input is an editorial tier based on how providers position each model and where it stands on public benchmarks and arena rankings. Everything else in the index is calculated from published facts: list prices, context windows, licenses, input types and release dates.

Can a provider pay to rank higher?

No. Rankings come only from the formula on this page and the data on each model page. Sponsorships on LLModel are labeled and never change a score, an order or a verdict.
