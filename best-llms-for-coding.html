Best LLMs for coding

Every model in our directory that its provider positions for software work, from frontier models that refactor whole repositories to small open-weight models that autocomplete on a laptop.

32 modelsData checked October 10, 2026

Coding is where differences between models show up fastest. A stronger model fixes the bug on the first attempt; a weaker one spends tokens on retries. That makes list price a poor guide to cost per solved task, so treat this page as a shortlist and test the top candidates on issues from your own codebase.

Agentic coding tools send large contexts on every turn: whole files, test output, diffs and tool results. Input price and prompt caching usually matter more than output price, and a long context window keeps more of the repository in view.

How to choose

  • For multi-file changes, refactors and agents that run tests, start with frontier and advanced models that support tool calling and long context.
  • For inline completion and quick edits, latency beats peak quality: efficient and compact models answer faster and cost a fraction as much.
  • If code can't leave your network, shortlist open-weight models and size the hardware with the VRAM calculator.
  • Check independent coding leaderboards such as SWE-bench and Aider's leaderboards, then confirm on your own tasks.

Frequently asked questions

Which LLM is best for coding?

No single model wins every coding task. Frontier models generally handle complex, multi-file work best, while cheaper efficient models are often good enough for completions and small edits. Shortlist three models from this page and compare them on 20-50 real tasks from your repository, measuring solved tasks per dollar.

Is a bigger context window better for coding?

It helps when an agent needs many files, logs and test output in view at once. But every token in the prompt is billed on every call, so good retrieval of relevant files and prompt caching usually save more money than simply sending the whole repository.

Can I use an open-weight model for coding?

Yes. Several open-weight models in this list are positioned for coding and can run on your own servers, which keeps source code inside your network. Check the license and the GPU memory you need before you commit.
